# Quick EMR Guide for Doctors

## 🚀 5-Minute Consultation Guide

### Step 1: Record Vitals (30 seconds)
```
Enter in left panel:
- BP: 120/80
- Pulse: 72
- Temp: 98.6
- Weight: 70
- SpO2: 99
```

### Step 2: Document Visit (1 minute)
```
In center panel:
- Chief Complaint: "Fever since last night"
- Diagnosis: "Viral Fever"
- Symptoms: "High fever, body ache"
```

### Step 3: Write Prescription (2 minutes)
```
Click "Add Medicine" for each medication:

Medicine 1:
- Name: Dolo 650
- Dosage: 650mg
- Frequency: 1-0-1 (Morning-Afternoon-Night)
- Duration: 5 Days
- Quantity: 15
- Instructions: After food

Medicine 2:
- Name: Montair LC
- Dosage: 1 tablet
- Frequency: 0-0-1 (Night)
- Duration: 7 Days
- Quantity: 7
- Instructions: Before sleep
```

### Step 4: Order Lab Tests (30 seconds)
```
Check boxes for tests:
☑ CBC
☑ Malaria Test
```

### Step 5: Follow-up (15 seconds)
```
Set next visit date: [Select date]
```

### Step 6: Save & Print (30 seconds)
```
Click "Save & Complete"
→ Redirects to print page
Click "Print Prescription"
→ Hand to patient
```

**Total Time: 5 minutes** ✅

## 🎯 Indian Frequency Codes - Quick Reference

| Code | When to Use |
|------|-------------|
| **1-0-1** | Standard 3x daily (most antibiotics) |
| **1-0-0** | Morning only (thyroid meds, vitamins) |
| **0-0-1** | Night only (sleeping pills, some BP meds) |
| **1-1-1** | Severe infection (strong antibiotics) |
| **SOS** | Pain killers, fever medication |
| **STAT** | Emergency single dose |

## 💡 Pro Tips

### **Tip 1: Use Standard Abbreviations**
- OD (Once Daily) = 1-0-0
- BD (Twice Daily) = 1-0-1 or 1-1-0
- TDS (Three Times) = 1-1-1
- SOS (As Needed) = SOS

### **Tip 2: Common Dosages**
- Paracetamol: 650mg
- Antibiotics: 500mg or 625mg
- Syrups: 5ml or 10ml
- Tablets: Usually "1 tablet"

### **Tip 3: Standard Durations**
- Acute: 3-5 Days
- Moderate: 7 Days
- Chronic: 15-30 Days
- Antibiotics: Complete course (usually 5-7 days)

### **Tip 4: Quantity Calculation**
```
Frequency: 1-0-1 (2 tablets/day)
Duration: 5 Days
Quantity: 2 × 5 = 10 tablets (add buffer = 15)
```

## ⚠️ Important Reminders

### **Required Fields**
- ✅ Chief Complaint
- ✅ Diagnosis
- ✅ At least one field filled (don't save blank consultations)

### **Prescription Validation**
- All medicine fields are required
- Frequency must be selected
- Duration and quantity must be specified

### **Lab Tests**
- Selected tests create pending payment requests
- Patient must pay at billing counter
- After payment, tests appear in lab queue

## 📞 Need Help?

### **Q: Can I edit after saving?**
A: Currently no. Prescriptions are immutable once created. Document carefully.

### **Q: Patient wants printed prescription?**
A: Yes! After saving, click "Print Prescription" button.

### **Q: Lab tests not showing?**
A: Check Admin → Lab Tests to ensure tests are marked as "Active".

### **Q: Forgot to add medicine?**
A: You'll need to create a new follow-up appointment or contact patient.
