# Laboratory Queue

The Laboratory Portal connects the pathology and radiology departments with the rest of the hospital.

## Lab Request Queue

![Lab Queue](../assets/lab-queue.png)

When a doctor prescribes a blood test, X-ray, or MRI, it immediately appears in the Lab Technician's queue.

### Features
- **Categorization**: The queue is split between Pathology (blood, urine) and Radiology (X-Ray, MRI, CT Scan).
- **Status Tracking**: Track the status of every test from `Requested` -> `Sample Collected` -> `In Progress` -> `Completed`.
- **Barcode Generation**: Print sample collection barcodes directly from the queue to attach to test tubes.
