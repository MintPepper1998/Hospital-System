# Test Reports & Result Entry

Once a test is completed, the Lab Technician enters the results into the system.

## Result Entry Interface

![Lab Reports](../assets/lab-reports.png)

### Pathology Results
For pathology tests (like a CBC or LFT), the system loads a predefined template with all required parameters (e.g., Hemoglobin, WBC count, SGPT). 
- The technician simply types the values into the fields.
- The system automatically compares the entered value against the **Normal Reference Range**.
- If a value is critically high or low, it is automatically flagged in **bold red text** on the final report to alert the doctor.

### Radiology Reports
For radiology tests (like an X-Ray), the technician or radiologist uses a rich text editor to write the diagnostic findings and impression.

### Approval & Printing
Once results are entered, they are marked as `Completed`. The report is instantly available in the prescribing Doctor's EMR, and the patient can access a PDF copy via the Patient Portal.
