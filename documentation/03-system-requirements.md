# System Requirements

Before accessing the Hospital ERP, make sure your system meets the following requirements.

---

## Browser Requirements

| Browser | Minimum Version |
|---------|----------------|
| Google Chrome | v100+ (Recommended) |
| Microsoft Edge | v100+ |
| Mozilla Firefox | v100+ |
| Safari | v16+ |

> **Tip:** For the best experience, we recommend using **Google Chrome** on a desktop or laptop computer.

---

## Display

| Requirement | Recommended |
|-------------|-------------|
| Screen Resolution | 1366 x 768 or higher |
| Optimal Resolution | 1920 x 1080 (Full HD) |

The application is responsive and works on tablets, but a desktop screen is recommended for daily operations.

---

## Network

| Requirement | Details |
|-------------|---------|
| Internet | Stable broadband connection |
| Minimum Speed | 5 Mbps |
| Recommended Speed | 10+ Mbps |

> **Important:** The system is cloud-hosted on AWS. A stable internet connection is required for all operations.

---

## Access URL

Open your browser and navigate to your hospital's deployment URL:

```
https://your-hospital-domain.com
```

You will see the login page. Proceed to [Login & First Steps](login.md) for instructions.
